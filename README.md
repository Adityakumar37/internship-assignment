# Elementum Figma to React

Responsive React implementation of the provided Elementum design screenshot.

## Run locally

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Build for submission:

```bash
npm run build
```

## Structure

- `src/components/Header.jsx`
- `src/components/HeroSection.jsx`
- `src/components/StorySection.jsx`
- `src/components/OfferSection.jsx`
- `src/components/Testimonials.jsx`
- `src/components/NewsletterFooter.jsx`
- `src/styles.css`

The image assets in `public/assets` were cropped from the provided screenshot so the page can be assembled immediately. Replace them with original Figma exports if you download the source assets.
